연결되지 않음

설정에서 OAuth 클라이언트 ID를 입력하고 Google 계정에 연결하세요. Google 캘린더를 지정하면 앞으로 추가하는 일정은 Google에 직접 저장됩니다. 기존 일정은 별도 이전 버튼으로 옮겨주세요.

⚙ 연동 설정 · 가족별 캘린더 지정

Google Cloud에서 Calendar API를 활성화하고, 이 페이지의 HTTPS 주소를 OAuth 웹 클라이언트의 승인된 JavaScript 원본에 등록해야 합니다. 클라이언트 보안 비밀값은 입력하지 마세요.

구성원별 이메일이 필요하지 않습니다. 같은 Google 캘린더를 연결해도 일정에 가족별 구분을 기록합니다.

읽기 전용 캘린더는 일정 추가·수정이 불가능합니다.
PC에 저장된 기존 일정 Google로 이전

날짜를 선택해 일정을 확인하세요. Google 연결 후 해당 캘린더의 일정은 클라우드에 반영되고, 연결하지 않은 일정은 이 브라우저에 저장됩니다.
